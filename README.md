# نظام مسك وزعفران (Meska & Zafran) - POS & Cashier System

نظام نقطة بيع وكاشير متقدم ومتكامل مصمم خصيصاً لمتاجر الكيك والحلويات الفاخرة، مبني باستخدام **React 18، Tailwind CSS، و Lucide Icons** ومجهز ليعمل بشكل مستقل بالكامل (Offline-First عبر LocalStorage) تمهيداً للتغليف المكتبي كبرنامج حاسوب (Desktop Packaging).

---

## ✨ المميزات الرئيسية

1. **واجهة المبيعات السريعة (POS)**:
   - تصنيفات منتجات مرنة مع إمكانية إضافة أقسام فورية (`+ إضافة قسم`).
   - شبكة أصناف تفاعلية مع إمكانية إضافة منتجات وتعديل أسعارها فورياً بالنقر بالزر الأيمن أو اللمس المطول.
   - زران سريعان لـ **عربون حجز** و **متبقي حجز** لإدراج مبالغ الحجوزات النقدية مباشرة.
   - سلة تفاعلية متطورة تدعم **تعديل السعر المباشر أو الخصم للطلب الحالي فقط** دون المساس بأسعار القائمة الأساسية.
   - حاسبة الدفع مع فئات نقدية سريعة واحتساب فوري للباقي (Change Due).

2. **سجل حجوزات الكيك (Reservations)**:
   - استمارة حجز شاملة (قياس الكيك 0-4، العبارة المكتوبة، تاريخ ووقت الاستلام، العربون، والمتبقي).
   - متابعة الحالات (قيد التحضير، جاهز، تم التسليم) مع إمكانية تسليم الطلب وتحصيل المتبقي فورياً.

3. **أرشيف ومسجل الصرفيات (Expenses)**:
   - تسجيل سندات الصرف (المبلغ، البيان، يصرف إلى السيد، التصنيف).
   - خصم فوري من صندوق اليومية الحالية.
   - أرشيف دائم ومستقل لا يحذف عند تصفير اليومية مع فلاتر بحث متقدمة.

4. **الخزينة وتصفير الصندوق (Treasury & Z-Report)**:
   - معادلة الصندوق الحية: `(المبيعات المباشرة + مقبوضات العربون) - صرفيات اليومية = صافي الصندوق`.
   - زر **إغلاق اليومية وتصفير الصندوق** مع طباعة آلية لتقرير Z وأرشفة اليومية وبدء وردية جديدة.

5. **الطباعة الحرارية المخصصة (Strict 72.1mm on 80mm Roll)**:
   - قياس دقيق صارم `72.1mm` لمنع أي قص جانبي للنصوص على طابعات الإيصالات 80mm.
   - نماذج حرارية لوصل البيع، وصل حجز الكيك، سند الصرف، وتقرير Z مع التفقيط العربي التلقائي.
